## 👨‍💻 About Me

I'm a **Junior C# / .NET Developer** and a Software Engineering student at **IT Park University**. My focus is the backend: designing REST APIs with **ASP.NET Core**, modeling data with **EF Core** and **PostgreSQL**, and shipping everything in **Docker** with **CI/CD**.

I learn by building real things, so most of my projects live where I spend my own time: **Telegram bots and Mini Apps**. Along the way I've worked with JWT authentication, real-time features via SignalR, third-party API integrations, and multilingual interfaces. I also completed the **EPAM Campus .NET Development Lab**.

Right now I'm looking for my **first internship or junior position** where I can grow into a strong .NET backend engineer.
